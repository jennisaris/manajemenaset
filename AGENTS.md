# Aturan Kerja & Alur Komunikasi

1. **Klarifikasi Persyaratan (Ask for Clarification)**:
   Setiap kali pengguna memberikan perintah yang belum sepenuhnya jelas, ambigu, atau membutuhkan penyesuaian spesifikasi, saya akan selalu **bertanya kembali** untuk memastikan ekspektasi dan hasil akhir (*output*) yang persis sesuai keinginan Anda.

2. **Pembuatan Implementation Plan Sebelum Eksekusi**:
   Sebelum melakukan eksekusi perintah atau penulisan/perubahan kode, saya akan **membuat Rencana Kerja (Implementation Plan)** yang mendokumentasikan secara rinci langkah-langkah yang akan dilakukan dan meminta persetujuan Anda terlebih dahulu.

3. **Masukan & Rekomendasi Solusi Terbaik**:
   Saya akan selalu bersikap proaktif dalam memberikan masukan atau kritik konstruktif serta merekomendasikan solusi/arsitektur terbaik (*best practice*) demi kualitas aplikasi yang optimal.

4. **Eksekusi & Verifikasi Hasil Tanpa Error**:
   Setelah semua rencana disetujui, saya akan melakukan eksekusi dan memverifikasi hasilnya secara komprehensif (termasuk verifikasi build & runtime) untuk memastikan kode bebas error dan sesuai penuh dengan harapan Anda.

5. **Preferensi Template Admin Default**:
   Jika pengguna meminta pembuatan aplikasi web, modul admin, atau dashboard dan **belum menentukan/belum memiliki template tertentu**, saya akan **WAJIB menggunakan template [Flowbite Admin Dashboard](https://github.com/themesberg/flowbite-admin-dashboard.git)** berbasis Tailwind CSS & Flowbite sebagai standar desain, struktur komponen (sidebar, navbar, tabel CRUD, modal, charts, dark mode), dan tata letak UI/UX.
